ClipBot Privacy Policy

ClipBot is a personal tool used only by its owner. It uses YouTube API Services to upload videos to the owner's own YouTube channel. By using ClipBot, you agree to be bound by the YouTube Terms of Service (https://www.youtube.com/t/terms).

Data handled through Google services is covered by the Google Privacy Policy: http://www.google.com/policies/privacy

Data collected

ClipBot only asks for permission to upload videos to the owner's own channel. It does not collect, store, share or sell data about any other person. The login token is stored only on the owner's own computer.

Revoking access and deleting data

Access can be revoked at any time at https://security.google.com/settings/security/permissions. Deleting the token file from the owner's computer removes all stored authorization data.
